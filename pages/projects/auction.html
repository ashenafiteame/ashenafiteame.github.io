Academic project · MIU · 2022

Real-Time Auction System

An event-based platform for real-time online auctions.

The problem

Auctions revolve around changing bids and timely updates. This academic project explored an event-based approach to the experience.

What I built

Developed a platform enabling real-time online auctions using Java, Spring Boot, React, and Kafka.

Technology choices

The project stack included Spring Config, Zipkin, MongoDB, PostgreSQL, Docker, and GitHub Actions alongside Spring Boot and Kafka. It provided a setting to work across backend services, data, and the user interface.

Context

Completed at Maharishi International University in 2022. This is a project summary, not a claim about production scale or measured performance.
