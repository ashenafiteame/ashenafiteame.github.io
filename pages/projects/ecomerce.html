Academic project · MIU · 2022

Online Shopping System

A shopping system covering the path from browsing a catalog to placing an order.

The problem

An online shopping flow has to connect catalog browsing, a persistent cart, checkout, and order history. This academic project brought those functions into one system.

What I built

Developed a shopping application with persistent cart behavior, purchases, product browsing, and order history. Integrated web services to retrieve data from banking systems and used Jess for business logic and validation.

Engineering focus

The project connected application logic, persistence, security, and external web services. It used Spring, Hibernate, Spring Security, MySQL, and Jess, with an Agile Scrum approach.

Context

This was an academic project completed at Maharishi International University in 2022. No public live demo is linked.
